# LAB-JOB

연구실 잡무를 **격주(2주) 순번**으로 공평하게 자동 배정하는 웹 앱.
서버·로그인 없이 링크 하나로 팀원 모두가 같은 배정표를 봅니다.

## 🔗 사이트 바로 가기

### 👉 https://bio-ej.github.io/lab-job/

## 사용법
1. 위 링크를 엽니다. (설치·로그인 없음)
2. 상단에서 **내 이니셜**을 한 번 누릅니다 → 내 차례가 강조되고 이 기기가 기억합니다.
3. **이번 2주 배정표**에서 내가 맡은 잡무와 규칙을 확인합니다.
4. 아래 **고정 업무**(상시 담당)와 **다가오는 회차**(다음 차례 미리보기)도 볼 수 있습니다.
5. 필요하면 **인쇄 / 이미지 저장**으로 단톡방에 공유하세요.

> 멤버·잡무 변경은 관리자에게 요청하면 모두의 화면에 자동 반영됩니다.

## 특징
- 회차마다 한 칸씩 밀리는 로테이션 → 담당 횟수가 완전히 균등
- "내 이름" 선택 시 내 차례 강조 + 이 기기가 기억
- 고정 업무 · 다가오는 회차 타임라인 · 인쇄/이미지 저장
- 설정(멤버·잡무·시작일·주기) 편집 후 "공유 링크 복사"로 배포

## 기술
외부 의존성 없는 단일 `index.html`. GitHub Pages로 호스팅됩니다.
